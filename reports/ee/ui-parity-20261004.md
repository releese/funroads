# Shared Netherlands and Estonia UI acceptance, 4 October 2026

## Implemented

- Country control beneath FunRoads, outside Browse and available during loading
  and errors. Smaller 12/16 px text, chevron, underline on hover/press,
  visible keyboard focus and transparent 44 px touch target.
- Native country links preserve project paths and other query parameters,
  clear route/detail context, and use the chosen country's default home.
- Explicit country source and quiet descriptions. EE does not claim traffic
  or population inputs, missing circuit distances, or modeled reach times.
  Nearby copy uses the selected radius rather than a fixed 100 km claim.
- Partial catalogue failures show a retry action as well as the surviving
  routes. Malformed-record warnings alone do not offer a pointless retry.
- No scoring, catalogue geometry, route identity or routing changes in this UI
  pass. The preceding circuit-only cleanup remains unchanged.

## Validation

- Python: **119 passed, 3 skipped**. Existing unknown network-marker warning.
- Frontend: **126 Vitest + 6 Node passed**. Typecheck, production build and
  packaged/offline-version integrity passed. Existing Base Web warnings.
- Four NL/EE × phone/desktop journeys cover diacritic-tolerant road search,
  home changes, save isolation, empty results/reset, details and Maps endpoints.
- Both countries have total-failure → partial-load → successful-retry tests.
- Real browser recovery was verified by blocking only EE's linked catalogue:
  706 circuit/sprint routes remained usable; unblocking and Retry route data
  restored all 790 routes and removed the retry warning.
- Browser: 24 longest-name circuit/sprint/linked-open/linked-loop samples at
  1789×1288, 1024×768 and 390×844. Details fit, scrolling bodies have no
  horizontal overflow, Navigate remains visible, waypoint limits hold, and
  closing details retains selection.
- Both country menus fit at 320×740, with smaller stacked labels, no branding
  overlap on hover, 44 px targets, and Escape focus return.
  The country name and FunRoads both start at x=12 px. Box-hover screenshots
  describe superseded iterations; the final hover cue is an underline.
- Focused native EE → NL → Back checks preserved the saved-route set.
  An earlier full browser run reported a changed storage fingerprint while
  using the live, user-visible pane. No cause was established; it is not
  represented as a clean pass. The focused check and unit regressions passed.
- ASCII `rongu` produced actual Rõngu road suggestions with real keyboard input.
  An earlier synthetic-fill probe did not open the suggestion list and timed
  out; it was not a search-engine failure.

Evidence: `ui-parity-browser-20261004.ps1`, its JSON measurements, header

## Limits and release

An axe check of the open country menu found zero violations but two incomplete
rules: ARIA-controls reference determination and contrast over the map canvas.
The referenced element was confirmed present manually. Canvas contrast is not
certified. This is not exhaustive accessibility or physical-device acceptance.

No new Android/iOS Maps-app trial, actual device offline-retention test, or
Teeregister redistribution-rights determination was performed. External Maps
can reroute and country catalogue readiness does not cache basemap tiles.

The user authorized main, including automatic Pages deployment, and all
project sources/tests/evidence. Raw downloads, generated graph caches,
dependencies, environments and build output are excluded. Linked-routing
investigation remains deferred.
